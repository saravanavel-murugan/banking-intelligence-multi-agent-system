================================================================================
                        PART 1: SETUP (10 minutes)
================================================================================

STEP 1: Check Python Installation (1 minute)
---------------------------------------------
Open PowerShell in your project folder:

    python --version

Expected: Python 3.8 or higher

If not installed: Download from python.org


STEP 2: Install Required Packages (5 minutes)
----------------------------------------------
In PowerShell, run:

    pip install -r requirements.txt

You'll see installation progress for:
✓ crewai
✓ langchain-openai  
✓ jupyter
✓ python-dotenv
✓ openai

Wait for: "Successfully installed..."


STEP 3: Get OpenAI API Key (3 minutes)
---------------------------------------
1. Go to: https://platform.openai.com/api-keys
2. Sign up / Log in
3. Click "Create new secret key"
4. Copy the key (starts with sk-...)
5. Add payment method (Settings → Billing)

⚠️ COST: About $1-5 for full testing


STEP 4: Create .env File (1 minute)
------------------------------------
In PowerShell:

    Copy-Item .env.example .env

Open .env in Notepad and replace:

    OPENAI_API_KEY=your-openai-api-key-here

With your actual key:

    OPENAI_API_KEY=sk-proj-abc123xyz...

Save and close.

================================================================================
                        PART 2: RUNNING (15 minutes)
================================================================================

STEP 5: Start Jupyter Notebook (1 minute)
------------------------------------------
In PowerShell:

    jupyter notebook

Browser will open automatically showing file list.

-------------------------------------------
Click on:

    ✅ banking_system_fresh.ipynb

    ❌ banking_multiagent_system.ipynb
    ❌ banking_multiagent_system1.json.ipynb

================================================================================
                        COMMON ISSUES & FIXES
================================================================================

❌ Problem: "ModuleNotFoundError: No module named 'crewai'"
✅ Solution: Run `pip install -r requirements.txt`

❌ Problem: "OPENAI_API_KEY not found"
✅ Solution: 
   1. Check .env file exists
   2. Verify no typos in API key
   3. Restart Jupyter kernel

❌ Problem: "AuthenticationError: Incorrect API key"
✅ Solution:
   1. Get new key from platform.openai.com
   2. Update .env file
   3. Kernel → Restart in Jupyter

❌ Problem: "You exceeded your quota"
✅ Solution:
   1. Add payment method at platform.openai.com
   2. Check billing settings
   3. Verify account has credit

❌ Problem: Notebook runs very slowly
✅ Solution:
   1. Check internet connection
   2. Try off-peak hours
   3. Consider using gpt-3.5-turbo (faster, cheaper)

❌ Problem: Python not found
✅ Solution:
   1. Install from python.org
   2. Check "Add to PATH" during install
   3. Restart PowerShell
